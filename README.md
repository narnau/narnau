## What I've been up to

I built [**YapScore**](https://yapscore.ai/), an AI-powered music notation editor that lets you edit and generate sheet music using natural language. Instead of navigating complex notation software, you simply describe what you want:

- “Transpose the whole piece to G major”
- “Add a crescendo in measures 4–8”
- “Write a 16-bar jazz waltz in Bb for piano”

YapScore understands the musical intent, modifies structured score data (MusicXML), renders the updated notation instantly, and provides in-browser MIDI playback. You can export to standard formats compatible with MuseScore, Finale, Sibelius, Dorico, and other notation tools.

Before YapScore I was CTO of [**Anything App**](https://anything.so/), an AI-powered assistant that combines an LLM agent with human operators to handle tasks for busy professionals via WhatsApp. I led the end-to-end build and deployment of the product, working deeply on AI agent architecture, including orchestration, tool use, context management, and designing reliable AI workflows in production.
